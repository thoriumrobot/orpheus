How to run the tools

      

        In this console — type a line in the Commander, put the caret on it, press Ctrl+Enter:

          eval (add 2 3) — run any Latte expression (std · mold · num · tensor · plan · ml linked)

          eval (fit_demo 2000) — train the linear-regression model; learns [w b]

          eval (tdot (tfromnats [1 [2 [3 0]]]) (tfromnats [4 [5 [6 0]]])) — tensor dot product

          type head [1 2] — infer an expression's type  ·  sca ligā — sound change

        Other pages — /editor (WYSIWYG Facet editor, edits the hosted pages) ·
        /chart (data visualization).

        From a terminal — latte ml --iters 5000, latte tensor,
        latte chart line 3 1 4 1 5, latte plan,
        latte mocha --app forge …, latte team --as NAME …, latte repl.
      

      
Quick commands

      
Each button drops a starter command into the Commander. eval links the std, mold, num, tensor, plan and ml libraries, so the numeric tools are reachable through it.
