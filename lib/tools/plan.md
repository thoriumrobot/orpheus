# Plan.Tool — economic planning
*Towards a New Socialism* (Cockshott & Cottrell): labour values (v = l + vA), Leontief gross
outputs, labour-token accounting, market-clearing steering, harmony balancing. All arithmetic
in lib/plan.lat.

[The 3-sector demo](run: plan demo3) [Two-sector classic](run: plan 40 0 1000) [Open the manual](run: System.Edit planning)

## Custom economies
Write a spec (sector/demand/market/labour lines) in the /plan page form, or POST it to
/api/plan — the format is in the manual above.
